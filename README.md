# CV Dance Classes – Premier Dance Academy 💃🕺

Welcome to **CV Dance Classes**, a modern and responsive dance academy website built with React and Vite. This project showcases dance styles, gallery, videos, special programs, and contact details for students interested in joining professional dance training.

## 🌟 Features

* Responsive modern website design
* Home page with academy introduction
* Dance styles section
* Image gallery
* Video section
* Special programs
* Contact page
* Fast performance with Vite
* Clean UI and reusable React components

## 🛠️ Tech Stack

* React
* TypeScript
* Vite
* CSS / Tailwind (if used)
* JavaScript

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/GitHritwiK84/CV-Dance-classes.git
```

### 2. Navigate to project folder

```bash
cd CV-Dance-classes
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run development server

```bash
npm run dev
```
